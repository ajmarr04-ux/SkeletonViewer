- `radiocapitate_ligament_left`: Texts differ on whether this is a separate band or part of the radioscaphocapitate ligament; described as a palmar radiocarpal band from the radial styloid to the capitate.
- `ulnocapitate_ligament_left`: Not named consistently across references (Gray's and TA2 group the palmar ulnocarpal fibres differently); described from the TFCC/ulna to the capitate. Please review.
- `ulnopisiform_ligament_left`: Described in some texts as part of the palmar ulnocarpal complex and not named by Gray's; attachments (ulna/TFCC to pisiform) are hedged.
- `ulnolunate_ligament_left`, `ulnotriquetral_ligament_left`: Origin is the TFCC (articular disc) rather than the ulna itself in many texts; connects lists `ulna_left` only because the TFCC has no ID.
- `dorsal_ulnocarpal_ligament_left`: Not a TA2 or Gray's standard term; described cautiously as a dorsal ulnar-side band from ulna/TFCC to triquetrum.
- `dorsal_scaphotriquetral_ligament_left`, `palmar_scaphotriquetral_ligament_left`: Described in the carpal-instability literature, not all anatomy texts; Latin forms are constructed on the TA2 pattern.
- `dorsal_intercarpal_ligaments_left`: Grouped set; `connects` lists all seven carpals except the pisiform and `joint` is `wrist_joint_left` although the set also spans intercarpal pairs outside that functional joint.
- `ulnar_collateral_ligament_wrist_joint_left`: Connects lists ulna and triquetrum only; some texts add the pisiform.
- `pisohamate_ligament_left`, `pisometacarpal_ligament_left`: No dedicated joint exists; `pisotriquetral_joint_left` chosen as the joint of the pisiform. Consider `null` if the main agent prefers.
- All files: `latin` for ligaments not in the standard TA2 list (see above) is on the TA2 pattern; `commonName` set to null throughout.
