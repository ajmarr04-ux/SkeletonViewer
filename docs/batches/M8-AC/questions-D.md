- `dorsal_carpometacarpal_ligaments`, `palmar_carpometacarpal_ligaments`: no functional joint covers carpometacarpal joints 2-5, so `joint` is the pair joint `carpometacarpal_joint_capitate_mc3_left` as the nearest fit. A functional "carpometacarpal joints 2-5" entry in joints.json would be better. Carpal bones listed are the usual ones (capitate, hamate, trapezium, trapezoid); texts differ on exact slips.
- `dorsal_metacarpal_ligaments`, `interosseous_metacarpal_ligaments`, `palmar_metacarpal_ligaments`: span the 2-3, 3-4 and 4-5 intermetacarpal joints; no functional set exists, so `joint` is `intermetacarpal_joint_3_4_left` and `connects` lists metacarpals 2-5.
- `collateral_interphalangeal_ligaments_hand`, `palmar_interphalangeal_ligaments`: the set covers PIP and DIP joints (and the thumb IP); `joint` is `proximal_interphalangeal_joints_hand_2_5_left` and `connects` lists the finger phalanges 2-5 only (thumb phalanges omitted). A broader functional joint may be wanted.
- `radiate_carpal_ligament`: texts vary on which bones it reaches (scaphoid, lunate, triquetrum from the capitate in Gray's); `joint` is `wrist_joint_left` (midcarpal part).
- `triquetrocapitate_ligament`: there is no triquetrum-capitate pair articulation, so `joint` is `wrist_joint_left`. Not every text names this ligament separately (often grouped with the scaphocapitate as the arcuate or deltoid ligament).
- `scaphotrapeziotrapezoidal_ligament`: three bones, no single pair joint; `joint` is `intercarpal_joint_scaphoid_trapezium_left`.
- `pisotriquetral_ligament`: Latin form `Ligamentum pisotriquetrum` is from memory of TA2; please check. Several other Latin forms (the plural collateral and palmar IP and MCP ligaments) are also my best recollection of TA2.
- `deep_transverse_metacarpal_ligament`: `connects` lists metacarpals 2-5 only; the ligament actually joins the palmar plates of the MCP joints, which have no ID.
